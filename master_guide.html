🚨 Important: Be Honest About Limitations

Your project has real limitations (identified from code). Interviewers respect honesty:

  1. CORS is too permissive (allows all origins)
  2. OTP uses Math.random() (not cryptographically secure)
  3. Files stored locally (not cloud)
  4. Stats query is inefficient (loads all docs to count)
  5. No input validation library
  6. No automated tests
  7. Video files accessible without auth (static serving)
  8. No global error handling middleware

Know these. If asked, say: “I’m aware of this limitation. Here’s how I’d fix it…”
