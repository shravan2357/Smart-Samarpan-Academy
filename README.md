# 🎓 Smart Samarpan Academy

An AI-powered full-stack learning platform for mathematics (Classes 9th–12th, JEE & Boards).

[![Live Frontend](https://img.shields.io/badge/Vercel-Live_App-black?style=flat&logo=vercel)](https://smart-samarpan-academy.vercel.app)
[![Backend API](https://img.shields.io/badge/Render-Backend_API-informational?style=flat&logo=render)](https://smart-samarpan-academy.onrender.com)

---

## ✨ Features

- **🤖 AI Tools:** AI-powered Quiz Generator, Formula Assistant, and Smart Recommendations using Google Gemini API.
- **📚 Course Management:** Structured curriculum, video lectures, and formula sheets for Classes 9–12.
- **🔐 Auth & Payments:** Email/Password & Google OAuth authentication, integrated with Razorpay payments.
- **👨‍💻 Admin Dashboard:** Role-based access control, user management, and course creation tools.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS, KaTeX
- **Backend:** Node.js, Express.js, MongoDB (Mongoose)
- **Services:** Google Gemini AI API, Razorpay Payment Gateway, Google OAuth

---

## 🚀 Deployment

- **Frontend App:** [smart-samarpan-academy.vercel.app](https://smart-samarpan-academy.vercel.app)

## ⚙️ Local Setup

1. **Clone Repo:**
   ```bash
   git clone https://github.com/kumarsuman-dev/Smart-Samarpan-Academy.git
   cd Smart-Samarpan-Academy
   ```

2. **Run Backend:**
   ```bash
   cd server
   npm install
   npm run dev
   ```

3. **Run Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
